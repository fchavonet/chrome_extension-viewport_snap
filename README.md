# Viewport Snap

## Description

Viewport Snap is a lightweight Chrome extension designed to capture web pages quickly and download clean PNG screenshots directly from your browser.

It provides three different capture modes: the currently visible viewport, the entire page, or a custom area selected directly on the page.

Full-page captures are automatically generated by scrolling through the page, capturing each section, and stitching them together into a single image. The extension also handles scrollable containers and fixed or sticky elements to produce cleaner screenshots and reduce duplicated interface elements.

Everything runs locally in your browser. No account, remote server, external API, or cloud service is required.

Whether you need to quickly save what is currently visible, document an entire web page, or capture a specific interface element, Viewport Snap provides a simple and minimal solution directly from your browser toolbar.

## Objectives

- Capture the currently visible browser viewport.
- Capture complete web pages in a single PNG image.
- Capture a custom area selected directly on the page.
- Automatically stitch multiple screenshots for full-page captures.
- Handle fixed, sticky, and scrollable page elements as cleanly as possible.
- Automatically download screenshots with generated filenames.
- Keep all capture and image processing operations local.
- Use minimal browser permissions.
- Provide a simple interface that automatically adapts to the system light or dark theme.

## Installation & Usage

### Installation

1. Clone this repository:
    - Open your preferred Terminal.
    - Navigate to the directory where you want to clone the repository.
    - Run the following command:

```
git clone https://github.com/fchavonet/chrome_extension-viewport_snap.git
```

2. Open a Chromium-based browser (Brave, Edge, Google Chrome...) and navigate to:

```
chrome://extensions/
```

3. Enable Developer Mode (top-right corner).

4. Click on "Load unpacked" and select the project folder.

5. The extension should now appear in your extensions menu.

> You can pin it to your browser toolbar via your extensions menu.

### Usage

1. Open the web page you want to capture.

2. Click the Viewport Snap icon in your browser toolbar.

3. Select one of the three available capture modes:
    - Visible Area: captures the currently visible browser viewport.
    - Full Page: automatically scrolls through the page and combines the captured sections into a single PNG image.
    - Select Area: lets you draw a custom selection directly on the page and captures only the selected area.

4. Once the capture is complete, the PNG image is automatically downloaded by your browser.

5. Generated files use a filename containing the website hostname, capture type, and timestamp.
